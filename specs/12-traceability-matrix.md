## Notas de trazabilidad

- Ningún RF de este documento carece de al menos un caso de uso asociado (verificado en esta iteración).
- Las columnas API/Componente/Prueba se cerrarán progresivamente: **Fase 2** define contratos de API (`08-api-contract.md`), **Fase 4 en adelante** define componentes concretos, **Fase 10** cierra la columna de pruebas.
- Cuando se cree cada archivo `/specs/features/*.md` (formato obligatorio de `prompt.md` §29), este documento debe actualizarse con el enlace real y no solo la referencia planeada.
- Regla de gobierno (prompt.md §39-40): ningún requisito aprobado se modifica silenciosamente; todo cambio a un RF/BR ya aprobado debe registrarse aquí y en un ADR si afecta arquitectura.
